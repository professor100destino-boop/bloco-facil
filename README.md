# Bloco Fácil

Corretor gratuito da Prova de Bloco (SEDUC-GO) por leitura de bolinhas, feito para professores da rede estadual de Goiás.

- O celular lê o cartão-resposta pela câmera, sem internet e sem IA paga.
- - A extensão do Chrome preenche os acertos no SIAP; o professor confere e clica em Salvar.
  - - Os dados dos alunos ficam só no celular e no navegador do professor.
